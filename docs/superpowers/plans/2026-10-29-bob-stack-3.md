# Stack Round 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A slower drop into the stack, the glowing light (B · Glow), an unmistakable end (2 · Circle), no "Lichte versie" or
3D switch in the header, and Portle in place of Porfael.

**Architecture:** Five independent changes to the existing React Router + R3F site: the light's look values
(`src/engine/bob/build/light.ts`), the land's lengths (`src/state/chapters.ts`, `src/scene/bob/worldPath.ts`), the header
and the stored 3D choice (`src/ui/SiteHeader.tsx`, `src/state/store.ts`), the Q&A's end (`src/ui/QaRing.tsx`,
`src/ui/qaWriters.ts`, `src/styles/base.css`) and the project data (`src/data/*`). Then the proof harness.

**Tech Stack:** React Router 8 (prerendered), React Three Fiber, three 0.186, zustand, Vitest, tsx, sharp, Playwright
(the harness).

**Spec:** `docs/superpowers/specs/2026-10-29-bob-stack-3-design.md`

## Review Focus

1. A visitor who stored `needle-3d=off` before this round loads the home: 3D is on (Task 3, `'ignores a stored choice from before'`).
2. One scroll up from the end: the dark and the circle go, `data-qa-end` is gone, the ring is back on question 6 (Task 4, `'leaves the end with nothing of it left'`).

5. A device that cannot run 3D still gets the card that offers the light version (Task 3, `'still offers the light version where 3D cannot run'`).
