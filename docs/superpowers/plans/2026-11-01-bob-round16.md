# Round 16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The tower's projects breathe on every floor all the time, a dial of Bob's name and line turns on the start screen's glass, Jontai's page shows the redesign as it is now, and the first floor's projects are both clear of the core.

**Architecture:** Four independent pieces on branch `bob-r16`. Breathing is a pure breath function (`src/scene/bob/breathe.ts`) the Void passes to the world build as `WorldPose.breath`; the world build scales each project and socket by it. The dial is a new engine part (`src/engine/bob/build/dial.ts`) built with the Opening's loader parts and posed by Home from the rise. Floor 1 is a turn constant in `worldPath.ts` plus a sight-line test. Jontai is data and a picture.

**Tech Stack:** React Router 8 (prerendered), React Three Fiber / three 0.186.1 with `frameloop="demand"`, Vitest, tsc, the Playwright-core proof harness `tools/proof/needle.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-01-bob-round16-design.md`

## Global Constraints

- NL is the default and EN is under /en/. The dial uses the existing copy only: the hero's `name` and the `badge` line (src/i18n/nl.ts, en.ts). The Jontai picture's alt and caption are the spec's exact strings.
- Reduced motion: nothing breathes (`b = 0.5`, a steady lift) and the dial does not turn.
- The BOB from above and everything after the floors keep their look.
- `.impeccable/config.json` is never edited. No subagents. Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No push or merge without Bob's word.
- The harness (`tools/proof/needle.mjs`) is updated for what changes and stays green.
- Test command for a task: `npx vitest run <files>`; the whole suite: `npx vitest run` and `npx tsc --noEmit -p .`.

## Rulings made while planning (from reading the code)

- **The breath runs on the page's time, not the world clock.** The spec said the world clock would keep running. At rest, the storm already redraws the canvas 30 times a second on the high and medium tiers (`stormMoves`, `STORM.fps`), so the breath rides on those frames at no extra cost, as round 10's floor glow did with `performance.now()`. The world clock's rule (`worldClockRuns`) and the harness's "the canvas draws the storm alone" checks stay as they are. If this is wrong, the cost is the low tier: there the storm stands still, so after 12 s at rest the tower holds its last breath until the next input.
- **The dial turns on the page's time for the same reason.** At home after the drift the canvas draws the storm alone at 30 fps, and the dial turns on those frames. The sleep check stays valid.
- **A project risen to the spot does not breathe** (its light × `1 + 2.2·b·(1 − risen)`), so the open project stays the one steady focus.
- **The floor-1 test's clearance is 2 m from the tower's axis.** Measured on today's code, Portle's sight line passes 1.05 m from the axis (1.10 m on a phone). With the extra −40° it passes 3.16 m (3.26 m). Every other sight line passes at least 3.34 m.
