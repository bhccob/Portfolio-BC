# Milestone 4: The Change Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carry the compass on `/lab/compass/` (NL) and `/en/lab/compass/` (EN) through the rest of the story, every step reversible by scrolling back:
1. **The current (What I work with):** one of the Erasmus bridge's cables lifts off the ring and becomes Ørsted's wire over the needle. Pulses of current swing the needle.
2. **The change:** the wire winds into a coil, the rings become mirror platters, the needle becomes the read/write arm, and the base plate becomes the chassis.
3. **The tracks (Projects):** each project is a track; the head steps across them, and each track's four test points pass under it.
4. **The spindle (Off duty):** "What keeps me spinning", with the hobbies orbiting.
5. **The Q&A:** a small, dimmed drive at the side, beside plain questions.
6. **Say hello:** everything folds back into the compass, and the needle points at the visitor.

**Architecture:**
- **One timetable:** the pure `Choreography` grows to every section. The pixel positions come from the page (`spansFromOffsets`), so the Q&A can be as tall as its content.
- **Pure geometry helpers** (`instrument/drive.ts`: arm bearing, head point, track radii) decide the drive's shape. They are tested in node.
- **New three.js parts:**
  - `Wire` (the cable, Ørsted's wire, the coil)
  - the drive's parts inside `Instrument` (platters, clamp, hub, chassis, magnets, ramp, the needle's travel to the arm)
  - `Tracks` (tracks, test points, hit rings, Q&A sectors)
- **`CompassScene` applies all of this** through a new `applyPose` glue module, so the scene file stays readable.
- **The page:** it adds the sections, words, anchors, the Q&A, the overlay labels and the hobby orbit.

```ts
// wirePath.ts (three-free)
export const WIRE: { points: 96; radius: 0.006; height: 0.11; lying: { from: readonly [190, 0.78]; to: readonly [205, 0.97] }; coil: { radius: 0.03; turns: 8; length: 0.12 }; pulseWidth: 0.08 };
export type Point = readonly [x: number, y: number, z: number];
export function lyingPath(): Point[];                     // a straight chord lying on the Rotterdam ring (bearing°, radius) → (bearing°, radius), y 0.002
export function straightPath(): Point[];                  // Ørsted's wire: north rim to south rim along x = 0 at y WIRE.height
export function coilPath(anchor: Point, axis: Point): Point[]; // a helix around `axis` through `anchor` (the arm's tail), WIRE.coil
export function wirePath(lift: number, wind: number, anchor: Point, axis: Point): Point[]; // lying → straight (an arc lifting mid-way) → coil
// Wire.ts
export interface WireModel { mesh: THREE.Mesh; set(pose: { show: number; lift: number; wind: number; pulse: number }, anchor: Point, axis: Point): void; materials(): THREE.Material[]; dispose(): void }
export function buildWire(): WireModel;                    // lives in the dial's frame
```

**Values:**
- **Paths:** each has exactly `WIRE.points` points.
  - **The lift:** straight while `lift` runs 0→1, with each point raised by 0.25·sin(πt)·sin(π·lift)·(distance from the chord's middle), so the cable arcs as it pulls up.
  - **The wind:** point i moves from the straight path's i to the coil's i, eased by smoothstep(wind).
- **The tube:**
  - Its vertices are rebuilt in place from the path (8 sides), only when the inputs change. No new geometry per frame.
  - Material: cream `#f1e8d3`, metalness 0.6, roughness 0.35. The colour lerps to gold `#d9a520` with `wind`. Opacity = `show` (transparent).
- **The pulse:**
  - An emissive band of signal yellow along the tube's u (0..1 along the path), centred at `pulse` with WIRE.pulseWidth, strength 2.4.
  - None when pulse < 0.
