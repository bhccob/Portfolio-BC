# Bob Chung Portfolio

A static portfolio website powered by Vite.

## Development

Install dependencies once:

```powershell
npm install
```

Start the local development server:

```powershell
npm run dev
```

Vite will print a local URL, usually `http://localhost:5173`.

## Production

Create an optimized deployment build:

```powershell
npm run build
```

The generated website is placed in `dist/`. Preview that build locally with:

```powershell
npm run preview
```

## Project structure

- `index.html` - page markup
- `assets/css/style.css` - visual design and responsive styles
- `assets/js/app.js` - language and theme controllers
